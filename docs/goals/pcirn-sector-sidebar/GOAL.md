# Goal: PCIRN sector-based sidebar

Use the approved design and execute `docs/superpowers/plans/2026-08-14-pcirn-sector-sidebar.md`.

Core rules:

- Reuse DSpace communities, collections, memberships, and resource policies as the source of truth.
- Support users in multiple `PCIRN_Setor_*` groups.
- Treat NUGECID as a sector while preserving the existing `NUGECID` workflow group.
- Keep administrators global and do not expose unauthorized sector objects.
- Capture evidence for one-sector, multi-sector, denied-access, admin, and NUGECID workflow paths.
