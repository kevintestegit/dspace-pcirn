# PCIRN Internationalization (i18n) & Item Localization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ensure language selection in DSpace works consistently across the entire application by configuring global fallback, localizing custom PCIRN UI templates (Home, Footer, User Menu), synchronizing translation catalogs, and dynamically translating document types while preserving original item content.

**Architecture:** 
1. Enable `translate.setDefaultLang(environment.fallbackLanguage || 'en')` in `InitService` to safeguard all active DSpace languages.
2. Synchronize all custom PCIRN keys into `pt-BR.json5` and `en.json5`.
3. Replace hardcoded strings in `home-page.component.html`, `pcirn-home-data.service.ts`, and `footer.component.html` with semantic i18n keys.
4. Implement a standalone `PcirnDocumentTypePipe` to translate `dc.type` values (`PORTARIA`, `DECRETO`, `LEI`, `POP`, etc.) across item pages and publication cards, falling back gracefully to raw values.

**Tech Stack:** Angular 19 / DSpace Angular, `@ngx-translate/core`, Node.js `node:test`, JSON5.

- [ ] **Step 2: Implement `PcirnDocumentTypePipe`**

Create `src/app/shared/utils/pcirn-document-type.pipe.ts` with standalone pipe:
```typescript
import { Pipe, PipeTransform } from '@angular/core';
import { TranslateService } from '@ngx-translate/core';

@Pipe({
  name: 'dsPcirnDocumentType',
  standalone: true,
})
export class PcirnDocumentTypePipe implements PipeTransform {
  constructor(private translate: TranslateService) {}

  transform(value: string | null | undefined): string {
    if (!value) return '';
    const normalizedKey = value.trim().replace(/\s+/g, '_').toUpperCase();
    const translationKey = `pcirn.document-type.${normalizedKey}`;
    const translated = this.translate.instant(translationKey);
    return translated !== translationKey ? translated : value;
  }
}
```
